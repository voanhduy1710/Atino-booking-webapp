# Atino Booking Webapp — Project Description

## Overview

A supplier delivery booking system for Atino's distribution warehouse. Suppliers (NCC — Nhà Cung Cấp) use the web app to register delivery appointments. Warehouse staff receive and validate bookings. Managers oversee all activity through reports.

The system is modeled after similar warehouse booking platforms (e.g., AEON delivery booking), adapted for Atino's internal workflows.

---

## Core Actors

| Actor | Vietnamese | Role |
|---|---|---|
| Supplier | NCC (Nhà Cung Cấp) | Books delivery slots, submits PO/delivery info |
| Warehouse Staff | Nhân viên kho | Confirms delivery slips, scans QR at receiving |
| Manager | Quản lý | Views all data, approves bookings, accesses reports |

---

## Business Flow

### 1. Supplier Booking Registration

The supplier accesses the web app and completes the registration form (Đơn Đăng Ký Giao Theo Đơn Hàng):

**Section I — Supplier Information (Thông Tin Nhà Cung Cấp):**
1. **Kho giao hàng (Store/Warehouse):** Fixed — Kho Tân Hoàng Long
2. **Mã NCC (Supplier Code):** Selected from master data list (sourced from accounting/finance department)
3. **Tên NCC (Supplier Name):** Auto-populated when supplier code is selected
4. **Ngày đăng ký giao hàng (Date of Delivery):**
   - Registered **before 18:00** → delivery date = N+1
   - Registered **after 18:00** → delivery date = N+2
5. **Số lượng đơn hàng (Number of POs):** Supplier selects a quantity; the form dynamically generates that many PO rows
6. **Đơn hàng (PO table):** One row per PO, containing:
   - Mã sản phẩm / Mã quy trình (Product Code / Process Code)
   - Số lần giao (Delivery Round): 1st, 2nd, ..., final
   - **On 1st delivery only:** an additional column for Hóa đơn VAT (VAT invoice photo — mandatory)
   - Tổng số kiện/thùng đi giao (Total boxes/cartons being delivered in this batch)
   - Hình ảnh phiếu giao (Delivery slip photos — multiple uploads allowed)

**Section II — Transport Information (Thông Tin Vận Chuyển):**
7. **Khung giờ đăng ký (Delivery Time Slot):** One of:
   - 07:00 – 09:00
   - 09:00 – 11:00
   - 13:30 – 15:30
   - 15:30 – 17:00
8. **Ghi chú giao hàng (Delivery Note):** Pre-filled with standard Atino notice:
   > "Yêu cầu NCC mang đầy đủ phiếu giao hàng đã được chấp thuận. Trường hợp NCC không có phiếu giao, mã hàng thực tế khác với phiếu trên booking, Kho phân phối của Atino sẽ từ chối nhận hàng. Kính mong NCC chuẩn bị đầy đủ. Atino trân trọng cảm ơn!"

**After Submission:**
- System generates a unique **Booking Code** (e.g., `80072601100032`)
- A **QR code** is displayed linking to the booking record
- Supplier photographs or saves both for use at the warehouse gate

---

### 2. Warehouse Booking Confirmation (Lê Thiên Tình)

- Reviews submitted bookings before they are finalized
- Validates delivery slips: must be full colors, full sizes, minimum 800 units per color
- May partially accept bookings — e.g., if 5 POs submitted but only 3 are valid, confirms only 3
- Once confirmed, the system allows those POs to be booked for delivery on N+1

---

### 3. Warehouse Receiving (Lê Thiên Dũng)

- On the delivery day, warehouse staff scans the supplier's QR code
- System displays all valid/confirmed orders for that booking
- Staff records actual received quantities
- **If quantities differ from booking:** Atino does not record a valid return schedule; the supplier is still penalized for late delivery per Atino policy

---

### 4. Manager View

- View all booking records across suppliers
- Access reports and analytics (Power BI integration planned)
- Monitor daily delivery capacity

## Home Screen Navigation

The app's landing page (ĐƠN ĐĂNG KÝ) presents three entry points:

| Button | Purpose |
|---|---|
| Đăng ký giao hàng | Opens the delivery registration form |
| Hướng dẫn tạo đơn | Displays step-by-step guide for creating a booking |
| Quy trình giao nhận hàng | Displays the warehouse receiving procedure (also serves as a training tab for staff) |

## Deployment Context

- **Hosting:** Google Cloud Run
- **Database:** Supabase (PostgreSQL)
- **Max concurrent users:** ~50
- **Language:** Vietnamese UI, English codebase
