# Workflow

This document describes what happens when the website opens and how the Larkbase product/process catalog is synced into Supabase.

---

## Website Open Flow

```
User opens website
│
├─ Browser downloads Vite app bundle
│
├─ React mounts Providers
│         │
│         ├─ QueryClientProvider starts TanStack Query cache
│         └─ BrowserRouter starts route matching
│
├─ AppStartupSync runs once per page load
│         │
│         └─ Submit background sync request
│                   POST  Express API: /api/product-process/sync
│                   │
│                   ├─ Express route: server/routes/productProcess.ts
│                   │       Create Supabase service-role client
│                   │       Prepare Larkbase app/table/view identifiers
│                   │
│                   ├─ Read Lark credentials from server env
│                   │       Prefer LARK_TENANT_ACCESS_TOKEN if present
│                   │       Otherwise use LARK_APP_ID + LARK_APP_SECRET
│                   │       IF missing:
│                   │           Return config error
│                   │           Website still renders cached Supabase data
│                   │
│                   ├─ Request Lark tenant token
│                   │       POST https://open.larksuite.com/open-apis/auth/v3/tenant_access_token/internal
│                   │       Body: { app_id, app_secret }
│                   │       IF success:
│                   │           Receive tenant_access_token
│                   │       IF fail:
│                   │           Return Lark token error
│                   │
│                   ├─ Read Larkbase records
│                   │       GET /bitable/v1/apps/{app_token}/tables/{table_id}/records
│                   │       app_token: At3fbwyI5a1Ps1srOpxlhkfqgVf
│                   │       table_id: tblBWiFNkTKezuoY
│                   │       view_id: vewd1Ee0kY
│                   │       fields: ["Tên SP", "Mã đơn"]
│                   │       page_size: 100
│                   │       Continue while Lark returns page_token
│                   │
│                   ├─ Normalize rows
│                   │       Lark record id -> lark_record_id
│                   │       "Tên SP" -> product_name
│                   │       "Mã đơn" -> order_code
│                   │       Skip rows missing product_name or order_code
│                   │
│                   ├─ Write Supabase cache
│                   │       UPDATE product_process_catalog SET active = false
│                   │       UPSERT rows by lark_record_id
│                   │       SET active = true
│                   │       SET last_synced_at = now()
│                   │
│                   └─ Return
│                           Body: { synced, ts }
│
└─ AppRoutes renders current route
          │
          ├─ Route: /booking/new
          │         │
          │         ├─ Load booking form data in parallel
          │         │       Supabase: warehouses
          │         │       Supabase: supplier info
          │         │       Supabase: product_process_catalog WHERE active = true
          │         │
          │         ├─ Render PO rows
          │         │       Mã SP dropdown reads product_process_catalog.product_name
          │         │       Mã QT dropdown reads product_process_catalog.order_code
          │         │
          │         └─ User selects either Mã SP or Mã QT
          │                   Find selected catalog row
          │                   Set booking_items.product_code = product_name
          │                   Set booking_items.process_code = order_code
          │
          ├─ Route: /product-process
          │         │
          │         ├─ Load catalog table
          │         │       Supabase: product_process_catalog WHERE active = true
          │         │
          │         ├─ User searches
          │         │       Filter by product_name or order_code in browser state
          │         │
          │         └─ User clicks "Làm mới"
          │                   POST  Express API: /api/product-process/sync
          │                   Invalidate TanStack Query cache
          │                   Reload catalog table from Supabase
          │
          └─ Other route
                    Load normal route data
                    Startup sync continues in background
```

## Larkbase ETL Flow

```
Trigger ETL
│
├─ App startup
│         │
│         └─ AppStartupSync sends sync request after React mounts
│
└─ Manual refresh
          │
          └─ Personnel user clicks "Làm mới" on /product-process

POST /api/product-process/sync
│
├─ Authenticate to Lark
│         │
│         ├─ IF LARK_TENANT_ACCESS_TOKEN exists
│         │       Use it directly
│         │
│         └─ ELSE
│                 POST Lark tenant token endpoint
│                 Body: { app_id: LARK_APP_ID, app_secret: LARK_APP_SECRET }
│                 Receive tenant_access_token
│
├─ Fetch Larkbase pages
│         │
│         ├─ Query Base records endpoint
│         │       app_token = At3fbwyI5a1Ps1srOpxlhkfqgVf
│         │       table_id  = tblBWiFNkTKezuoY
│         │       view_id   = vewd1Ee0kY
│         │       field_names = ["Tên SP", "Mã đơn"]
│         │
│         └─ Pagination
│                 IF has_more = true:
│                     Request next page_token
│                 ELSE:
│                     Stop
│
├─ Transform records
│         │
│         ├─ For each Lark record
│         │       Read fields["Tên SP"]
│         │       Read fields["Mã đơn"]
│         │       Convert rich Lark cell values to plain text
│         │
│         └─ Output row
│                 {
│                   lark_record_id,
│                   product_name,
│                   order_code
│                 }
│
├─ Update Supabase
│         │
│         ├─ Mark old cache inactive
│         │       UPDATE product_process_catalog
│         │       SET active = false, updated_at = now()
│         │
│         ├─ Upsert latest rows
│         │       ON CONFLICT (lark_record_id)
│         │       UPDATE product_name, order_code, active, last_synced_at
│         │
│         └─ Result
│                 Active rows match latest readable Larkbase rows
│
└─ Response
          │
          ├─ Success
          │       Return { synced: number, ts: ISO timestamp }
          │
          └─ Failure
                  Return { error: message }
                  Frontend shows error only on manual refresh page
                  Startup failure stays silent so normal app usage continues
```

## Booking Form Catalog Flow

```
Supplier or admin opens /booking/new
│
├─ Load page requirements
│         │
│         ├─ Warehouses
│         │       SELECT id, code, name FROM warehouses WHERE active = true
│         │
│         ├─ Supplier context
│         │       Supplier user: read supplier from session
│         │       Admin user: choose active supplier account
│         │
│         └─ Product/process catalog
│                 SELECT * FROM product_process_catalog
│                 WHERE active = true
│                 ORDER BY product_name, order_code
│
├─ Render PO table
│         │
│         ├─ Column: Mã SP / Mã QT
│         │       First dropdown placeholder: "Mã SP"
│         │       Options: product_process_catalog.product_name
│         │
│         └─ Second dropdown placeholder: "Mã QT"
│                 Options: product_process_catalog.order_code
│
├─ User selects a catalog row
│         │
│         ├─ If selected from Mã SP dropdown
│         │       Use selected row id
│         │
│         ├─ If selected from Mã QT dropdown
│         │       Use selected row id
│         │
│         └─ Write hidden form fields
│                 product_code = selected.product_name
│                 process_code = selected.order_code
│
└─ User submits booking
          │
          └─ Existing finalize flow continues
                    POST /api/booking/finalize
                    booking_items.product_code stores Lark "Tên SP"
                    booking_items.process_code stores Lark "Mã đơn"
```

## Product Process Page Flow

```
Personnel user opens /product-process
│
├─ Route guard checks role
│         │
│         ├─ Allowed roles
│         │       warehouse_reviewer
│         │       warehouse_receiver
│         │       manager
│         │       admin
│         │
│         └─ Not allowed
│                 Redirect by RequireRole
│
├─ Load catalog rows
│         │
│         └─ SELECT * FROM product_process_catalog
│             WHERE active = true
│             ORDER BY product_name, order_code
│
├─ Render table
│         │
│         ├─ Column: STT
│         ├─ Column: Tên SP
│         ├─ Column: Mã đơn
│         └─ Column: Thời gian đồng bộ
│
├─ Search
│         │
│         └─ Filter loaded rows by Tên SP or Mã đơn
│
└─ Refresh
          │
          ├─ User clicks "Làm mới"
          ├─ POST /api/product-process/sync
          ├─ Show sync error if request fails
          └─ Invalidate catalog query if request succeeds
```

## Data Ownership

```
Larkbase
│
└─ Source of truth
          │
          ├─ Column: Tên SP
          └─ Column: Mã đơn

Express backend
│
└─ ETL owner
          │
          ├─ Stores Lark credentials in server env
          ├─ Calls Lark OpenAPI
          └─ Writes Supabase with service-role key

Supabase
│
└─ Application cache
          │
          └─ Table: product_process_catalog
                    Public SELECT only for active rows
                    Service-role writes during ETL

Frontend
│
└─ Consumer
          │
          ├─ Reads product_process_catalog through Supabase anon client
          ├─ Uses catalog rows in /booking/new selects
          └─ Triggers refresh through Express API
```
